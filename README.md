# Pépie

Messagerie où les vocaux s'écrivent tout seuls et où les textes se font écouter. Comptes, discussions à deux ou en groupe, résumés, roasts à trois niveaux, jeux.

- Front : un seul fichier `index.html` (hébergé par GitHub Pages)
- Back : Supabase (authentification, base Postgres avec sécurité par ligne, temps réel)
